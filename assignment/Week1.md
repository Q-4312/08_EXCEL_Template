## 01-3. 엑셀의 기본 동작 원리 이해하기
> **셀 참조 방식에 대해 정리해주세요.**
1-3. 엑셀의 기본 동작 원리 이해하기

1. 자동 채우기

사용법 : 커서 -> 드래그

- 패턴
문자 : 반복 출력
숫자
1개의 셀 선택 : 숫자를 반복해서 출력. Ctrl 누른 채 채우면 1씩 증가
2개 이상 선택 : 패턴 인식하여 자동 채우기. Ctrl 누른 채 채우면 반복 출력
날짜 : 입력된 값의 최소 단위(년/월/일)로 패턴 인식하여 자동 채우기
시간
1개의 셀 선택 : 시간 단위로 증가
2개 이상 선택 : 패턴을 인식하여 자동 채우기
셀 참조 : 상대 참조라면 자동 채우기 방향으로 참조되는 셀이 한 칸씩 이동
문자/숫자 혼합
문자는 반복, 숫자는 1씩 증가하거나 / 패턴 인식하여 자동 채우기
숫자 2개 이상 : 마지막 숫자만 변경(예: 1학년1반, 1학년2반, 1학년3반,...)
- 자동 채우기 옵션을 통해 다양한 옵션 선택 가능

빠른 채우기(단축키 : Ctrl + E)
기준 셀에 패턴을 인식할 수 있는 예시 값을 입력한 후 실행
+ 직접 실행하지 않더라도 사용자가 입력하는 데이터가 빠른 채우기 대상이라고 판단되면 엑셀에서 자동으로 인식하여 예상 데이터 목록을 시트 위에 출력하고, Enter를 누르면 빠른 채우기가 실행

셀 참조

셀 : A1, B1, C1, …
범위 : A1:B1, A1:C1, …
$ 기호 : 행/열을 고정할 때 사용, 행과 열을 모두 고정하거나 둘 중 하나만 고정 가능
상대 참조 : 다른 셀을 참조할 때 셀 주소 앞에 $ 기호 X (예: =A1, =C6+D6)
절대 참조 : 열과 행에 모두 $ 기호, 수식을 복사하거나 자동 채우기를 실행해도 셀 주소는 항상 고정됨(예 : =$A$1)
혼합 참조 : 행과 열 중 하나만 선택하여 고정하는 방식

* Ctrl + ‘ or [수식] 탭-[수식 분석] 그룹-[수식 표시] : 셀에 입력된 수식 확인 가능

4가지 연산자(기본적으로 알고 있는 것과 동일)
<> : 같지 않음
& : 텍스트 연결(텍스트 연산자)
: : 범위로 연결(참조 연산자)
, : 여러 셀/범위를 결합(참조 연산자)
띄어쓰기 : 두 범위 사이에서 중복된 범위(참조 연산자)

날짜/시간

날짜 기준 : 1900년 1월 1일(1900/1/1 = 1)
 -> 3 입력 >>> 1900/1/3
 -> 44562 입력 >>> 2022/1/1
하루 = 1 / 24시간 = 1 / 12시간 = 0.5 / 1분 ~= 0.0007

## 01-5. 실무자면 꼭 알아야 할, 필수 단축키 모음
> **이번에 배운 단축키에 대해 정리해주세요.**
Ctrl : 동시에 누르기
Alt : 차례대로 누르기
    ㄴ> 리본 메뉴에서 제공되는 거의 모든 기능을 단축키로 실행 가능
    ㄴ> Alt를 누르면 기능별 단축키가 표시되므로 별도 암기 불필요
Ctrl + S : 파일 저장
F12 : 다른 이름으로 저장
Shift + F11 : 새로운 시트 삽입
Ctrl + 시트 탭 드래그 : 시트 복제
Ctrl + N : 새로운 통합 문서
Ctrl + Tab : 통합 문서 간 이동
Ctrl + PageUp/PageDown : 이전/다음 시트로 이동
    ㄴ> 꾹 누르면 맨 처음/마지막 시트로 이동
Ctrl + Shift + PageUp/PageDown : 연속된 시트 다중 선택 가능
Ctrl + 마우스 휠 : 화면 배율 조절 = Ctrl + Alt + +/-
Alt -> P -> R -> S : 인쇄 영역 설정
Shift + F10 : 팝업 메뉴 열기
Ctrl + F1 : 리본 메뉴 숨기기
Ctrl + Shift + F1 : 전체화면 모드 전환
Ctrl + Shift + U : 수식 입력줄 확장
Alt -> W -> F -> F : 행/열 틀 고정
Ctrl + Shift + L : 자동 필터 적용 -> Alt + ↓ : 필터 옵션 활성화 -> E : 검색창 이동
Ctrl + \ : 선택 범위의 행/열 기준으로 다른 값 구분(좌우)
Ctrl + Shift + \ : 선택 범위의 행/열 기준으로 다른 값 구분(상하)
Ctrl + [ : 현재 셀의 수식에 참조되는 셀
Ctrl + ] : 현재 셀을 참조하는 셀
Ctrl + Shift + [ / ] : 이전/이후 단계의 모든 셀 선택
Ctrl + A : 활성화된 셀 기준 연속된 표나 범위 선택 -> 한 번 더 : 시트 전체 범위 선택
Alt + Enter : 셀 안에서 줄 바꿈
Ctrl + Alt + V : 선택하여 붙여넣기
Ctrl + F : 특정 단어가 들어간 셀 찾기
Ctrl + H : 특정 단어가 들어간 셀 변환
F4 : 이전 작업 반복
F2 / 더블클릭 : 활성화된 셀 즉시 편집
Ctrl + Z, Ctrl + Y : 실행 취소, 취소한 실행 다시 실행
Ctrl + Enter : 선택된 범위에 동일한 값이나 수식 입력(연속된 범위가 아니여도 가능)
Ctrl + + / - : 삽입 대화상자 / 삭제 대화상자
Shift + Spacebar : 전체 행 추가 or 삭제
Ctrl + D / R : 범위의 첫 번째 셀에만 값이 상태에서 아래 / 오른쪽 방향으로 자동 채우기
Ctrl + E : 빠른 채우기
Ctrl + 1 : 셀 서식 대화상자
Alt -> H -> B -> A : 선택된 범위 바깥쪽과 안쪽에 기본 테두리 적용
Ctrl + Shift + 7 : 선택된 범위 바깥쪽만 테두리
Ctrl + Shift + - : 선택한 범위에 적용된 모든 테두리 삭제
Alt -> H -> H -> N : 선택한 범위의 모든 채우기 색상 삭제
Ctrl + Shift + ‘ : 일반 서식(예: 1000)
Ctrl + Shift + 1 : 숫자 서식(예: 1000->1,000)
Ctrl + Shift + 2 : 시간 서식
Ctrl + Shift + 3 : 날짜 서식
Ctrl + Shift + 4 : 통화 서식(예: 1000 -> $1,000)
Ctrl + Shift + 5 : 백분율 서식(예: 0.1 -> 10%)
Ctrl + Shift + 6 : 지수 서식(예: 1000 -> 1.00E+03)
Ctrl + 방향키 : 범위의 마지막 셀로 이동
Ctrl + End : 중간에 빈 셀이 있는 표에서 마지막 셀 이동
Ctrl + Shift + 방향키 : 표의 끝까지 한 번에 선택
Ctrl + Backspace : 현재 활성화된 셀로 이동
Ctrl + Home / End : [A1]셀 / 마지막 셀로 이동
F5 or Ctrl + G : 이동 대화상자
Ctrl + Space / Shift + Space : 행 / 열 전체 선택
Alt + ; : 선택된 범위에서 보이는 데이터만 선택
Alt + Shift + 좌/우 방향키 : 선택한 범위를 그룹화 / 그룹 해제
Ctrl + 9 / 0 : 행/열 숨기기 / 보이기      


## 02-1. 보기 좋은 표, 활용할 수 있는 데이터를 위한 필수 상식
> **데이터와 표를 비교해주세요**
표는 구분자가 세로, 가로 둘 다 있고, 데이터는 세로로만 되어있어 관리에 용이하다.
특히 특정 값을 찾을 때 표의 수식을 손수 입력해야 하는 번거로움이 있지만, 데이터는 정렬 기능이 있어 편하다.

> **셀 병합 기능을 자제해야 하는 이유를 정리해주세요.**
범위 선택 제한
범위의 수정/편집 제한
표 기능과 피벗 테이블 사용 제한
자동 채우기를 제대로 활용 불가
데이터 정렬 기능 사용 불가
함수를 사용할 때 옳지 않은 결과 반환 가능성
